# Pagination

## Properties

| Name            | Type        | Description                      | Notes      |
| --------------- | ----------- | -------------------------------- | ---------- |
| **limit**       | **Integer** | Items per page                   | [optional] |
| **offset**      | **Integer** | Items to skip                    | [optional] |
| **total**       | **Integer** | Total number of items            | [optional] |
| **hasNext**     | **Boolean** | Whether there are more items     | [optional] |
| **hasPrevious** | **Boolean** | Whether there are previous items | [optional] |
