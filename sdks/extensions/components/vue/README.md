# Vue component examples — unsupported

This directory is retained only as historical, non-production example code. It is not a package, is
not published to npm, has no supported build, and is not exported by any WRFCoin release artifact.

The examples may contain incomplete or simulated behavior. Do not use them for wallet creation,
sensor collection, release integrations, or production UI. Supported consumers should use the
documented API and SDK packages instead.

Any future Vue package must be designed, secured, tested, and released as a separate productization
effort; this tree must not be presented as available in the meantime.
