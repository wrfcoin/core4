What's next

Nodes take on more over time. You climb by reliable time on the rung below, not by computer power.

  1. 1

    Sync node You are here

    Keeps its own checked copy of the chain and shares blocks with other nodes. Leave it running: time online is what counts for the next step. A sync node is not paid.

  2. 2

    Bonded node Preview

    Locks a 250.36 WRF bond and serves chain snapshots to new nodes, and is paid each epoch (about 11 hours) for that service. Newcomers can get the bond once, as a faucet bond grant, after their node has been a visible peer for 24 hours. Needs a P2P address other nodes can reach.

Open your port (TCP 9000)

A bonded node must be reachable by other nodes. You open exactly one port, TCP 9000 (the node's peer-to-peer port). This page and the node's API stay on this computer (127.0.0.1) and are never reachable from outside.

  1. Give this PC a fixed address on your network: in your router, reserve its current address (often called "DHCP reservation"). PowerShell shows the address: Get-NetIPAddress -AddressFamily IPv4.
  2. Forward TCP 9000 on your router to that address, port 9000. One rule, nothing else. Note the router's public (WAN) address.
  3. Allow it in Windows Firewall. In PowerShell as administrator: 
    New-NetFirewallRule -DisplayName 'WRFCoin node P2P (TCP 9000)' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 9000 -Program "$env:LOCALAPPDATA\Programs\WRFCoin Node\launch_api.exe" -Profile Any
    If you once answered Cancel to the firewall prompt, remove that block rule first (the full guide shows how).
  4. Tell the node. Create %LOCALAPPDATA%\WRFCoin\reachable.conf with your public address in the second line: 
    WRFCOIN_P2P_HOST=0.0.0.0
WRFCOIN_P2P_EXTERNAL_ADDR=/ip4/203.0.113.7/tcp/9000
  5. Bonded mode (testnet). Once you have a server key (wrfcoin-node.ps1 -Action ServerKey) and your bond's service alias, add two lines to the same file: 
    WRFCOIN_P2P_SERVE_BONDED_SNAPSHOTS=1
WRFCOIN_SERVICE_ID=<your bond's service alias>
    The node refuses to start if any piece is missing, so a half-set-up node never runs.

Restart the node (Start menu: Stop WRFCoin Node, then WRFCoin Node). Reachable at above then shows your address, and Mode shows Bonded. Check from outside your network (a phone on mobile data): Test-NetConnection <your address> -Port 9000. To close the port, delete reachable.conf, restart, and remove the router and firewall rules.
