# WRFCoin Documentation Templates

This directory contains standardized templates for creating consistent documentation across the
WRFCoin platform.

## Available Templates

### 1. Quick Start Template (`quick-start-template.md`)

Use for getting users up and running quickly with a feature or service.

### 2. Tutorial Template (`tutorial-template.md`)

Use for step-by-step learning experiences that build specific skills.

### 3. API Reference Template (`api-reference-template.md`)

Use for documenting REST API endpoints, GraphQL queries, and SDK methods.

### 4. Architecture Decision Record (`adr-template.md`)

Use for documenting significant architectural decisions and their rationale.

### 5. Troubleshooting Guide (`troubleshooting-template.md`)

Use for comprehensive problem-solving documentation.

### 6. Integration Guide (`integration-guide-template.md`)

Use for third-party integrations and enterprise implementations.

## Usage Instructions

1. **Copy the appropriate template** to your documentation directory
2. **Rename the file** to match your content (e.g., `jwt-authentication-tutorial.md`)
3. **Fill in all template sections** following the style guide
4. **Remove any unused sections** but maintain the overall structure
5. **Review against the checklist** in each template
6. **Submit for review** following the documentation review process

## Template Conventions

All templates follow these conventions:

- **Placeholder text** is in `[brackets]` - replace with actual content
- **Optional sections** are marked with `(Optional)` - remove if not needed
- **Required sections** must be included in all documents
- **Code examples** should be complete and runnable
- **Links** should use relative paths for internal documentation

## Style Guide Compliance

Each template includes:

- ✅ Proper heading hierarchy
- ✅ Consistent terminology usage
- ✅ Code syntax highlighting
- ✅ Accessibility considerations
- ✅ Review checklist
