# Community Resources

**Date Created:** May 12, 2025  
**Last Edited:** May 26, 2025

Welcome to the Wrfcoin community! This page provides links and information about the various
resources available to community members, from developers to node operators to weather data
enthusiasts.

## Wrfcoin Forum

The official [Wrfcoin Forum](https://forum.wrfcoin.org) is the central hub for discussions about the
ecosystem. The forum includes:

- Technical discussions and support
- Governance proposals and voting discussions
- Research and development updates
- Community events and announcements
- Regional and language-specific subforums

## Developer Hub

The [Developer Hub](https://developers.wrfcoin.org) contains comprehensive resources for building on
the Wrfcoin blockchain:

- API documentation
- SDK downloads and guides
- Smart contract templates and examples
- Tutorials for different development environments
- Testing and debugging tools
- CI/CD pipeline examples

## Research Papers

The Wrfcoin ecosystem is built on solid scientific foundations. Our
[Research Portal](https://research.wrfcoin.org) provides access to:

- Academic papers on blockchain and weather forecasting integration
- Technical specifications for the Wrfcoin protocol
- White papers on consensus mechanisms and data validation
- Case studies of weather data applications
- Peer-reviewed publications by the core team and community members

## Tutorials

For those new to the ecosystem, we offer a range of [Tutorials](https://learn.wrfcoin.org):

- Setting up your first Wrfcoin node
- Creating and deploying Computational NFTs
- Building weather data applications
- Contributing to the ecosystem
- Participating in governance

## Governance Hub

The [Governance Hub](https://governance.wrfcoin.org) is where you can participate in shaping the
future of Wrfcoin:

- Active proposals and voting interface
- Governance forum discussions
- Voting history and analytics
- Delegate profiles and statistics
- Treasury management transparency reports
