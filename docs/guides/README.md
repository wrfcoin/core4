# Wrfcoin Core Documentation

## Overview

Welcome to the Wrfcoin Core documentation. This collection of guides provides comprehensive
information about the Wrfcoin blockchain ecosystem for different audiences. Whether you're a
developer, system administrator, or end user, you'll find the information you need to understand,
deploy, and use Wrfcoin Core effectively.

## Available Guides

### [Development Guide](./development/README.md)

The Development Guide is designed for developers who want to understand the architecture,
components, and development workflow of the Wrfcoin blockchain ecosystem. It covers:

- Architecture overview
- Technology stack
- Development environment setup
- Project structure
- Database schema and ORM
- API reference
- WebSocket services
- Core components
- Testing framework
- Contribution guidelines

### [Deployment Guide](./deployment/README.md)

The Deployment Guide provides detailed instructions for deploying the Wrfcoin Core blockchain
application in various environments. It includes:

- Deployment requirements
- Local deployment steps
- Testnet deployment
- Mainnet deployment
- Server configuration
- Database setup
- Security considerations
- Monitoring and maintenance
- Backup and recovery
- Troubleshooting

### [User Guide](./user/README.md)

The User Guide helps end users navigate and use the Wrfcoin Core desktop application effectively. It
covers:

- Getting started with Wrfcoin
- Installation instructions
- User interface overview
- Wallet management
- Blockchain explorer
- Mining and validation
- Environmental data submission
- Computational NFTs
- Cross-chain transfers
- Privacy features
- Settings and configuration
- Troubleshooting
- Frequently asked questions

### [WRF Token Cross-Chain Liquidity Path](./wrf-liquidity-path.md)

The Liquidity Path guide documents the full trading path from weather data submission through WRF
rewards, cross-chain bridging, and DEX swaps to BTC/USDC. It covers:

- Weather data submission and reward earning
- Cross-chain bridge operations (lock-and-mint)
- AMM pool swaps on Ethereum/Polygon
- CLI commands and API reference
- Safety controls, risks, and mitigations
