# Historical design notes (February 2026)

Superseded and design-only. These brainstorms and gap analyses were generated
early in the project to explore possible directions. They are kept for history and
are not documentation of the current chain 888 testnet. Anything they describe
that is not in the [implementation status](https://github.com/wrfcoin/docs/blob/main/STATUS.md)
is not offered. Some ideas (for example an NFT marketplace and cross-chain bridges)
remain planned for later. Their percentages and feature counts are not current
measurements.
