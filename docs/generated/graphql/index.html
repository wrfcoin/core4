🌍 Overview

The WRFCoin GraphQL API provides a comprehensive interface for interacting with the climate-focused blockchain platform. This API supports:

  • Weather Data Operations - Submit and query environmental sensor data
  • Blockchain Queries - Access transaction and block information
  • Wallet Management - Handle wallet operations and balance queries
  • NFT Operations - Mint, transfer, and query NFTs
  • Governance - DAO proposals and voting mechanisms
  • Carbon Credits - Environmental impact tracking and trading
GraphQL Endpoint: POST http://localhost:4000/graphql

Authentication: Most operations require authentication via JWT token in the Authorization header.
